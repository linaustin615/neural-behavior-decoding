How to read this: all three models see the same activity. Color shows activity above each cell’s training mean, clipped at +5 SD. Depth is imaging-plane number; plane spacing is schematic. Mouse gait illustrates speed, not recorded pose. Playback uses native frames, not verified seconds.

Evidence, source data, and limits

These are saved predictions from independent fits on seven separate Stringer-coauthored Facemap recordings. Each model was trained within its recording; this is not zero-shot transfer. Coordinates are used for this view only, not by these decoders. The three displayed seeds are all the fixed training seeds; ridge is deterministic and does not change with seed.

Metrics cover the entire test interval for the selected seed. R² below zero means worse than the test-mean reference. MSE / zero speed above 1 means worse than always predicting no running. The study did not establish reliable transformer superiority. A visual match is not a significance test.

The 512 original neuron indices and their published x/y/plane positions stay aligned with the model input. Color values are quantized to 8 bits for display; full precision archived predictions determine the metrics. No neurons, seeds, recordings or test frames were selected based on visual appeal.
