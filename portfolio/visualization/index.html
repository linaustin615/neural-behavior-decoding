Evidence, source data, and limits

These are saved predictions on four sensorimotor mice: D3, D4, D7 and D9. The mix combines a transformer and an MLP; the correction is the original bounded attention+BCE branch. Each model was trained within its recording; this is not zero-shot transfer. Coordinates are used for this view only, not by these decoders. The three displayed seeds are all fixed paired parent seeds (correction seeds are +200); ridge is deterministic and does not change with seed.

Metrics cover the entire test interval for the selected seed. R² below zero means worse than the test-mean reference. MSE / zero speed above 1 means worse than always predicting no running. The mix beat both standalone models in the original holdout study. The ridge comparison is post hoc. The correction only improved overall MSE by 1.16% and missed its improvement gate. This replay does not establish accuracy.

The 512 original neuron indices and their published x/y/plane positions stay aligned with the model input. Color values are quantized to 8 bits for display; full precision archived predictions determine the metrics. The viewer includes all four mice and all test frames. The README excerpt uses the first mouse and seed and an observed-behavior-only selection rule.
