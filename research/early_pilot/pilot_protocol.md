**Pilot protocol — fixed before transformer outcome inspection, September 24, 2026**

Purpose: decide whether an anatomy-aware neuron transformer warrants a larger project. Running speed is the sole predictive target. This is an exploratory pilot, including a previously inspected recording, not a preregistered confirmatory study.

Three independent mice: MP019 (Neuromatch's public Stringer sample), MP027 and MP028 (original public Stringer recordings). MP019 uses the supplied bins, documented by Neuromatch as 1.2 seconds. The two raw 12-plane recordings average three adjacent frames for activity and running speed, approximately 1.2 seconds at the paper's 2.5 Hz volume rate. Exact original timestamps are not provided in these files. Neural and behavioral arrays were already resampled to a common imaging time by the data authors. The primary split is chronological 60%/20%/20% train/validation/test with 50 bins discarded on each side of internal boundaries and full input windows restricted to retained blocks.

For each mouse, a fixed seed (20260924) selects 1,024 neurons: 512 may be used in model training, and 512 are excluded from model fitting. Training uses random subsets of 128 neurons per update. At test time, predictions are averaged across four fixed subsets of 128 cells. Unseen-neuron tests use only the excluded pool, at held-out test times. Excluded neurons' unlabeled training-period traces supply normalization statistics; thus this measures transfer without labeled training on those cells, not transfer without any calibration. Splits, neuron pools, sample schedules and evaluation subsets are identical across paired conditions.

The model has two transformer layers, width 32, four heads, feed-forward width 64, dropout 0.05, an eight-bin activity embedding, and a CLS readout. Positional features use eight logarithmically spaced frequencies per axis and an MLP. There are no temporal-sequence position embeddings across neurons. Distance attention uses Euclidean distance after each coordinate axis is centered and scaled by its training-pool range. This tests normalized geometry rather than calibrated micrometer distances. All models contain the same modules; the condition determines which modules receive gradients. Explicit ID parameters are included only in the ID conditions' forward passes.

Five paired training seeds (0–4), AdamW with initial learning rate 0.001 and weight decay 0.01, batch size 32, 1,600 updates per run, 50-update warm-up and cosine decay to 20% of peak learning rate. Validation occurs every 200 updates using two fixed neuron subsets. The checkpoint with the lowest validation MSE is evaluated on test data. Test scores do not select checkpoints or hyperparameters. Each run is compared with its untrained initialization. No early stopping changes the matched training budgets.

MP019 conditions at full labeled-data budget: no coordinates, real coordinates, fixed shuffled coordinates, ID only, ID plus real coordinates, ID plus shuffled coordinates, depth only, normalized-distance attention, shuffled-distance attention, within-depth shuffled coordinates, and three recording-quality conditions (real, globally shuffled, and within-depth shuffled coordinates). Quality features are each neuron's training-period mean and standard deviation plus the supplied noise estimate; transforms and scaling use training data only. Coordinate shuffles are separate within the fitted and unseen neuron pools, fixed within each run, and preserve the coordinate multiset. Within-depth shuffles preserve each neuron's depth.

Additional MP019 checks: real versus shuffled coordinates at 10% and 25% labeled training data (nested selections of 2 or 5 of 20 training-time blocks), plus five shifted-target real-coordinate fits. Normalization retains access to unlabeled training-period activity for all label-budget conditions. Null labels are circularly shifted separately within each retained train/validation/test interval; no labels move across partitions. These shifts are controls, not an assumption that the null R² must equal exactly zero.

MP027 and MP028 each repeat real/shuffled coordinates, ID-plus-real/ID-plus-shuffled, depth-only, within-depth shuffles, and real/shuffled normalized-distance attention across five seeds. Ridge regression is fit as an activity-only reference for each mouse, including an ensemble on the same four test neuron subsets. An unseen-neuron ridge fit, where reported, is a supervised reference trained on those cells and is not a transfer baseline.

Before interpreting results: verify finite inputs, disjoint window support, shuffle integrity, neuron-permutation invariance, finite gradients, and the model's ability to overfit 64 examples. A synthetic positive control will test whether the architecture can learn a deliberately imposed spatial relationship. Log numerical failures and incomplete gates rather than presenting them as negative scientific results.

Decision criteria: examine paired changes in test R² and their variation across seeds and mice, performance relative to ridge and untrained models, low-label and unseen-neuron behavior, depth/quality controls, and training curves. A single favorable run is insufficient. Consistent gains across mice and controls justify expansion; small mixed gains support a narrower follow-up at most. Failure to fit or severe underperformance limits what a null anatomy result can establish. Five training seeds are technical repeats, not five biological samples; three mice remain a small pilot.

Temporary scripts and downloads stay outside the project. Retain the protocol, numerical results, source/config hashes, and a readable report; remove temporary material after completion.

Implementation clarification: the distance conditions use pairwise distance attention bias without xyz token embeddings. Ridge and transformer evaluation inputs are matched, but the transformer samples the full 512-cell training pool while each ridge component fits its fixed 128-cell subset.

The sweep was restarted with existing full-label results retained; both configuration hashes are recorded.

Exploratory follow-up after first-mouse transfer results: add depth-group-mean ridge ensembles on the same four neuron subsets, evaluated on familiar and excluded neurons, with shuffled depth-group controls. These are simple transfer references, not additional transformer hypotheses. Supplied noise metadata may reflect whole-recording preprocessing; the quality-feature controls are supplementary, while their mean/std activity features and scaling use training data. The transformer feed-forward activation is PyTorch’s default ReLU; its positional MLP uses GELU.
